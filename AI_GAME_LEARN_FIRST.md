# AI game learner flow

AI-generated games are immediately playable. There is no separate AI-generated learning-step screen.

1. **Play directly**: the game itself contains a clear instruction for the learner.
2. **Answers hidden during play**: correct indices, bins, sequence order and memory pairs are not shown as an answer key before completion.
3. **Review at the end**: after completion, the result screen exposes **View Answers & Review** with the correct responses.
4. **Mobile**: drag-sort supports both desktop drag-and-drop and touch-friendly tap-item → tap-destination interaction.
