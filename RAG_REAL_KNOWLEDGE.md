# Real-Knowledge RAG — LearnAble

## What is now grounded
LearnAble's RAG knowledge base contains:

1. The FACP guideline summary used by the application.
2. Page-level extracts from the uploaded **Functional Assessment Checklist for Programming (NIMH), 120-page source**.
3. The project's mapped FACP digital catalogue.
4. Learner-specific FACP observations (filtered by `studentId`).
5. Active approved LearningModule content.

## Why this is real knowledge
The official FACP pages are not generated by the LLM. They are extracted from the project-provided source PDF and stored as retrieval chunks with page metadata. The LLM receives retrieved source text as context and is instructed to stay grounded in it.

## Example
A query such as `brush teeth`, `wash hands`, `toileting`, `sorting vegetables`, or `count money` can retrieve the actual FACP checklist page containing the corresponding activity, plus the project mapping and relevant approved module.

## Privacy
Learner assessment chunks carry `metadata.studentId`. Retrieval for a learner includes generic FACP/module knowledge plus only that learner's assessment chunks. One learner's assessment is not supplied as context for another learner.

## Seed
From `backend`:

```bash
npm run seed:rag
```

The seed reports the total number of chunks inserted. Re-run it after changing the FACP source, catalogue, or approved module data.
